# Saiful Islam — GitHub Pages portfolio

Static career site built from [Saiful Islam](https://github.com/SaifulSaif007)’s CV. No build step. Open `index.html` locally, or host it on GitHub Pages.

Live URL after you publish: `https://saifulsaif007.github.io/`

## Upload to GitHub Pages

1. Create a **public** GitHub repository named `SaifulSaif007.github.io` (must match your GitHub username).
2. Upload every file in this folder to the **root** of that repo:
   - `index.html`
   - `404.html`
   - `.nojekyll`
   - `css/`
   - `js/`
   - `assets/`
3. In the repo: **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: `main` (or `master`) / folder: `/ (root)`
4. Wait a minute, then open `https://saifulsaif007.github.io/`

If you already have a `SaifulSaif007.github.io` repo, push these files to its default branch instead of creating a new one.
